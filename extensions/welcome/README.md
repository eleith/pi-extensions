# welcome

my header card for when a new PI session starts.

![Large startup tree](large-tree.svg)

## why

i like 🌳. you like 🍎. we like 🥧.

## how to install

```sh
pi install npm:@eleith-pi/welcome
```

## how to use

just spin up a fresh pi instance.

or run `/eleith:welcome` and plant a new tree.

use `large`, `small`, or `tiny` to choose a size.

## how to configure

update `~/.pi/agent/extensions/eleith.json` with the following:

```json
{ "commandPrefix": "personal" }
```
